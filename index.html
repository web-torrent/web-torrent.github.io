WebTorrent

BitTorrent in the browser: the same swarms, the same pieces and hashes, with WebRTC between peers and a WebSocket to the tracker because a browser can open nothing else. The project is webtorrent.io — the library, the desktop app, the docs. This page is a service beside it: what is up, who speaks it, and the protocol written down.

The protocol, as data

WebTorrent never had a BEP: it is what the library does. Torrent Schema writes BitTorrent down in JSON-LD — bencode, metainfo, trackers, the peer wire — and WebTorrent as an overlay on it: the WebSocket tracker messages, the rule that the wire protocol runs over the data channel unchanged, and the things implementations get wrong (one offer per tracker, no a=ice-options:trickle, an answer is not a connection). A codec reads the schema and reproduces real torrents, real tracker answers and real peer sessions byte for byte — webtorrent's, and qBittorrent 5.3's.
