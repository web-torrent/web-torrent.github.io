# webtorrent.org

A service page for WebTorrent — BitTorrent in the browser — beside the project itself at https://webtorrent.io/: the public WebSocket trackers asked live from the visitor's browser, the clients that speak WebTorrent and since when, and the protocol written down as data ([Torrent Schema](https://torrent-schema.github.io/)).

The domain is held for the WebTorrent project and is theirs for the asking: open an issue. Nothing here is affiliated with or endorsed by the project.

Served from `gh-pages` as it is; no build. AGPL-3.0-or-later.
